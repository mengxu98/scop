# LINGER runner

This runner calls LingerGRN 1.110 through its public preprocessing, training and population-network functions. Its input and export protocol is adapted from the multiCSN manuscript's LINGER workflow. The LingerGRN package remains a separate dependency.

The implementation identity includes `trans_shap-missing-key-v1` and `tf-re-small-batch-v1`. The first fix moves the TF output loop inside the branch that verifies the trained SHAP key. The second initializes the completed-batch index to -1 before the TF-region batch loop so fewer than 50 target genes enter the remainder loop correctly. For complete batches the loop overwrites that initialization and retains its original values. The dependency is copied into the current run directory before applying these exact changes. The shared installation is not modified. The private preprocessing copy also replaces its hardcoded eight workers with the requested worker count. Model calculations are unchanged by the worker limit. Original and patched source hashes, the batch-patch hash, and the applied-patch flags are recorded.

Population RNA and ATAC count matrices must contain the same uniquely named cells. Sample and label metadata are written explicitly. The native method produces at least 50 pseudobulks before training because version 1.110 draws a fixed background of 50 without replacement. The upstream neural-network training fixes its own seed to 42. The requested scop seed controls the pseudobulk preparation and is recorded separately.

The three exported network layers retain the original finite nonzero LINGER scores. The complete RNA assay supplies the native pseudobulk PCA. Candidate regulator and target genes then restrict the pseudobulk expression rows passed into native preprocessing, and the endpoint-specific filters apply after fitting. LINGER scores are not interpreted as activating or repressing coefficients. No chains are created.

Original project: [LINGER](https://github.com/Durenlab/LINGER). Dependency licensing remains with the installed LingerGRN distribution. Runtime source files and original and patched source hashes are retained in each execution directory.

Reference identities use the shared `reference-files.json` specification. The selected input accessibility chromosomes determine the per-chromosome files; global mapping, motif, gene and TF reference files are always included. Both the R cache boundary and the independent Python runner verify the complete contents of the selected files. Other chromosomes and unused baseline/scNN reference files do not affect this LINGER population-mode identity.
