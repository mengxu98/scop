# Plots for metabolism pathway scoring

Plots for metabolism pathway scoring

## Usage

``` r
MetabolismPlot(
  srt = NULL,
  res = NULL,
  group.by = NULL,
  assay_name = "METABOLISM",
  ...,
  verbose = TRUE
)
```

## Arguments

- srt:

  A Seurat object containing the results of RunMetabolism.

- res:

  GSVA results generated by RunGSVA function. If provided, 'srt' and
  'group.by' are ignored.

- group.by:

  Grouping variable used in RunMetabolism.

- assay_name:

  Assay or tools slot containing metabolism results.

- ...:

  Additional arguments passed to
  [GSVAPlot](https://mengxu98.github.io/scop/reference/GSVAPlot.md).

- verbose:

  Whether to print messages.

## See also

[RunMetabolism](https://mengxu98.github.io/scop/reference/RunMetabolism.md),
[EnrichmentPlot](https://mengxu98.github.io/scop/reference/EnrichmentPlot.md)
