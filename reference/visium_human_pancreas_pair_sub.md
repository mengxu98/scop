# Compact two-sample human PanIN Visium example

A two-sample spatially covering subset from the public GSE254829
PanIN-LG1 and PanIN-LG2 Visium sections. Raw acquisition coordinates and
explicit sample_id labels are retained for multi-sample documentation
examples.

## Format

A Seurat object with 1000 genes, 440 spots, and two sample labels.

## Source

GSE254829 GSM8058242 and GSM8058244; generated by
<https://github.com/mengxu98/datasets/tree/main/SCOPExamples>.

## Examples

``` r
data(visium_human_pancreas_pair_sub)
table(visium_human_pancreas_pair_sub$sample_id)
#> 
#> GSM8058242 GSM8058244 
#>        220        220
```
