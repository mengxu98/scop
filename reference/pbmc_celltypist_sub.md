# Compact PBMC CellTypist example

A 400-cell RNA subset derived from pbmcmultiome_sub. When available, the
object includes CellTypist labels and confidence values generated by the
Immune_All_Low.pkl model; no Python native object is stored.

## Format

A Seurat object with 12405 RNA genes and 400 cells.

## Source

Derived from the bundled pbmcmultiome_sub; build metadata is recorded in
the SCOPExamples provenance entry.

## Examples

``` r
data(pbmc_celltypist_sub)
table(pbmc_celltypist_sub$CellType)
#> 
#>     B CD4 T CD8 T    DC  Mono    NK 
#>    63    70    69    66    70    62 
grep("^celltypist_", colnames(pbmc_celltypist_sub[[]]), value = TRUE)
#> [1] "celltypist_predicted_labels" "celltypist_conf_score"      
```
